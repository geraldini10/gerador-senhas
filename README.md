# 🔐 Gerador de Senhas

Gerador de senhas aleatórias com interface web, desenvolvido como projeto de estudo.

## 🛠️ Tecnologias utilizadas

- Java (lógica de geração de senhas)
- HTML, CSS e JavaScript (interface web)

## ⚙️ Funcionalidades

- Definir o tamanho da senha (6 a 32 caracteres)
- Escolher os tipos de caracteres: maiúsculas, minúsculas, números e símbolos
- Copiar a senha gerada com um clique
- Validação: exige ao menos um tipo de caractere selecionado

## 🚀 Como usar

1. Abra o arquivo `src/index.html` no navegador
2. Escolha o tamanho e os tipos de caracteres
3. Clique em **Gerar Senha**
4. Clique em **Copiar Senha** para copiar
